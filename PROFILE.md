## APIs

- **DuoPlus HTTP API** — Hosted REST-style HTTP/JSON API for managing cloud phones, subscriptions, proxies, groups, applications, cloud drives, automation, teams, and cloud numbers. All calls are POST with JSON, authenticated via a DuoPlus-API-Key header, using a code/data/message envelope and page/pagesize pagination. (`https://openapi.duoplus.net`)

> Documented hosted HTTP/JSON API at https://openapi.duoplus.net (POST /api/v1/..., DuoPlus-API-Key header, 1 QPS limit).
